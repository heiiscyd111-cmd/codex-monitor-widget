Codex 用量状态条（Windows 便携版）
=================================

一、前置条件

1. Windows 10 或 Windows 11（64 位）。
2. 已安装 Windows 版 Codex，并已登录自己的 ChatGPT/Codex 账户。
3. 至少启动过一次 Codex，使本地状态文件完成初始化。
4. 不需要安装 Node.js、Electron，也不需要 OpenAI API Key。

二、使用方法

1. 将整个压缩包解压到一个固定文件夹。
2. 不要直接在 ZIP 压缩包内运行。
3. 双击“CodexMonitor.exe”。
4. 打开 Codex 后，状态条会显示在屏幕顶部中央。
5. 绿色圆球表示任务正在运行，灰色圆球表示任务已完成。

三、显示内容

- Codex Plus 可用额度百分比
- 本周期下一次重置日期和倒计时
- 当前运行状态（绿色/灰色圆球）

四、自启动

首次运行后，小组件会登记为 Windows 登录启动项。
如不需要自启动，可在：
Windows 设置 → 应用 → 启动，中关闭 Codex Monitor。

五、注意事项

- 用量显示的是当前电脑登录账户自己的 Codex 用量。
- 如果一直显示“--”或“暂无重置时间”，请先启动 Codex 并确认已经登录，然后重新打开小组件。
- 移动解压后的文件夹后，请重新运行一次 CodexMonitor.exe，以更新自启动路径。
- Windows 首次运行可能显示安全提示；确认文件来自可信发送者后选择继续运行。

六、退出

在 Windows 系统托盘找到 Codex 状态图标，右键选择“退出小组件”。
