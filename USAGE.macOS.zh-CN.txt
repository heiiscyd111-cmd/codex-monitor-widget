Codex 用量状态条（macOS 内部试用版）

适用范围

1. macOS 14 或更高版本。
2. Apple Silicon（M 系列）Mac。
3. 已通过 Homebrew 安装并登录 Codex CLI：/opt/homebrew/bin/codex。

安装与首次启动

1. 解压 CodexMonitor-vX.Y.Z-macOS-arm64.zip。
2. 将 CodexMonitor.app 移到“应用程序”目录。
3. 首次启动若被 macOS 阻止，请在“系统设置 → 隐私与安全性”中选择“仍要打开”。
4. 启动后应用仅显示在菜单栏，不会常驻 Dock。

使用

- 左键点击菜单栏图标打开菜单。
- “显示 / 隐藏”控制悬浮组件。
- “立即刷新”重新读取额度和本地任务状态。
- “退出小组件”完全退出应用。

CLI-only 模式

本版本使用 Homebrew Codex 读取额度和 ~/.codex 下的本地任务状态，不要求安装 Codex 桌面应用。桌面应用启动检测、前台悬浮联动和 codex:// 跳转不可用。

未签名版本限制

- 首次启动需要手动信任。
- 任务完成系统通知不可用。
- 登录自启动仅尽力设置，可能不会生效。

隐私

应用只读取本机 Codex 状态，不上传对话、账号或额度数据，也不要求额外 API Key。
