Codex 用量状态条（macOS 内部试用版）

适用范围

1. macOS 14 或更高版本。
2. Apple Silicon（M 系列）或 Intel Mac。
3. 已安装并登录 Codex 桌面应用，或已通过 Homebrew 安装并登录 Codex CLI。

安装与首次启动

1. Apple Silicon 解压 CodexMonitor-vX.Y.Z-macOS-arm64.zip；Intel 解压 CodexMonitor-vX.Y.Z-macOS-x64.zip。
2. 将 CodexMonitor.app 移到“应用程序”目录。
3. 首次启动请按住 Control 点击 CodexMonitor.app，选择“打开”；若仍被阻止，请在“系统设置 → 隐私与安全性”中选择“仍要打开”。
4. 启动后应用仅显示在菜单栏，不会常驻 Dock。

使用

- 左键点击菜单栏图标打开菜单。
- “显示 / 隐藏”控制悬浮组件。
- “立即刷新”重新读取额度和本地任务状态。
- “始终置顶所有窗口”可让组件覆盖所有应用；取消后仅在 Codex 位于前台时悬浮。
- “退出小组件”完全退出应用。

订阅与有效期

- 小组件会从当前 Mac 自己的 ~/.codex/auth.json 中自动识别 Free、Plus、Pro 等套餐和订阅有效期。
- 登录令牌只在本机解析，不会打印、另存或上传。
- 若登录声明未提供有效期，可点击组件左侧日期区域手动设置。
- 没有 5 小时额度限制的账号会自动隐藏该模块并缩短组件。

完整桌面模式

安装 Codex 桌面应用后，小组件会优先使用应用内置 CLI，并提供：

- Codex 打开时自动显示小组件。
- Codex 位于前台时保持悬浮，切换到其他应用时恢复普通窗口层级。
- codex:// 深链接跳转。

这些检测使用 macOS Workspace API，不需要辅助功能、录屏或自动化权限。

CLI-only 模式

找不到桌面应用内置 CLI 时，小组件会使用 Homebrew Codex：Apple Silicon 路径为 /opt/homebrew/bin/codex，Intel 路径为 /usr/local/bin/codex。CLI-only 模式可读取额度和 ~/.codex 下的本地任务状态，但桌面应用启动检测、前台悬浮联动和 codex:// 跳转不可用。

未签名版本限制

- 首次启动需要手动信任。
- 任务完成系统通知不可用。
- 登录自启动仅尽力设置，可能不会生效。

隐私

应用只读取本机 Codex 状态，不上传对话、账号或额度数据，也不要求额外 API Key。
